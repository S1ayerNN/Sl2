Политика обработки персональных данных

Дата публикации: 1 мая 2026 г.

1. Общие положения

Настоящая Политика обработки персональных данных (далее — Политика) определяет порядок обработки и защиты персональных данных пользователей сервиса MyAstro (далее — Сервис), доступного по адресу https://myastro.space.

Оператор персональных данных: Гибалин Владимир Вадимович, контактный email: slayer89@bk.ru.

Используя Сервис, пользователь дает согласие на обработку своих персональных данных в соответствии с настоящей Политикой и Федеральным законом от 27.07.2006 N 152-ФЗ «О персональных данных».

2. Какие данные мы собираем

В процессе использования Сервиса могут обрабатываться следующие персональные данные:

  • Имя (псевдоним)
  • Дата рождения
  • Пол
  • Время рождения (при указании)
  • Место рождения (при указании)
  • Профессия (при указании)
  • Адрес электронной почты (при указании)
  • Интересы и предпочтения
  • Данные аутентификации (Telegram ID, Google ID)

3. Цели обработки данных

Персональные данные обрабатываются в следующих целях:

  • Предоставление персонализированных астрологических прогнозов
  • Идентификация и аутентификация пользователя
  • Улучшение качества Сервиса
  • Связь с пользователем (при необходимости)

4. Правовые основания обработки

Обработка персональных данных осуществляется на основании:

  • Согласия пользователя (п. 1 ч. 1 ст. 6 152-ФЗ)
  • Необходимости исполнения договора (оказания услуг Сервиса)

5. Способы обработки и защита данных

Персональные данные обрабатываются с использованием средств автоматизации. Оператор принимает необходимые организационные и технические меры для защиты персональных данных:

  • Чувствительные данные (имя, дата рождения, место рождения, профессия, email) хранятся в зашифрованном виде (AES-256)
  • Передача данных осуществляется по защищенному протоколу HTTPS
  • Доступ к базе данных ограничен
  • Пароли хешируются с использованием bcrypt

6. Передача данных третьим лицам

Персональные данные не передаются третьим лицам, за исключением:

  • Обезличенные данные (знак зодиака, пол, интересы) передаются провайдеру AI для генерации прогнозов
  • Случаев, предусмотренных законодательством РФ

7. Хранение данных

Персональные данные хранятся на территории Российской Федерации на серверах, расположенных в дата-центрах на территории РФ.

Данные хранятся в течение всего срока использования Сервиса и удаляются по запросу пользователя.

8. Права пользователя

Пользователь имеет право:

  • Получить информацию об обработке своих персональных данных
  • Требовать уточнения, блокирования или уничтожения персональных данных
  • Отозвать согласие на обработку персональных данных

Для реализации указанных прав направьте запрос на slayer89@bk.ru.

9. Файлы cookie

Сервис использует токены аутентификации (JWT), хранящиеся в локальном хранилище браузера. Сторонние cookie-файлы для отслеживания не используются.

10. Изменение Политики

Оператор вправе вносить изменения в настоящую Политику. Актуальная версия размещается по адресу https://myastro.space/privacy.html.
