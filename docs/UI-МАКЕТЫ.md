## 11. User Flow (Навигационная карта)

```
Авторизация
    │
    ├── Новый пользователь → Регистрация (3 шага) → Главный экран
    │
    └── Существующий → Главный экран
                          │
                          ├── 🔮 Получить гороскоп
                          │   ├── [Free] → Реклама → Генерация → Результат → Фидбек
                          │   └── [Plus/Premium] → Генерация → Результат → Фидбек
                          │
                          ├── 📜 История → Список прошлых гороскопов
                          │
                          ├── 👨‍👩‍👧 Семья
                          │   ├── Список членов
                          │   ├── Добавить → Форма → Сохранить
                          │   └── Гороскоп для члена → Генерация → Результат
                          │
                          ├── 👤 Профиль
                          │   ├── Редактирование данных
                          │   ├── Выбор интересов
                          │   └── Подсказка заполнения
                          │
                          └── ⚙️ Настройки
                              ├── Уведомления
                              ├── Подписка → Экран тарифов → Оплата
                              └── Выход
```
